Arrow — Pattern & Scoring System

C# · Unity Input System

Goal: reward precise, fast input and increase difficulty based on stages.

How it was built:

  • Each pattern is a list of arrow objects.
  • Each arrow holds an index for the direction it points, and the player's input maps to the same index system.
  • When the input matches the first arrow in the list, that arrow counts as correct and the game moves on to the next one.
  • Difficulty increases as more patterns are completed successfully.

A Bridge Too Dumb — Object Freezing, Outline Shader & Online Multiplayer integration

C# · Runtime Physics & Shader · Photon Pun 2

Goal: let players build bridges in real time with visual feedback and multiplayer synchronization.

How it was built:

  • Built on Rigidbody physics.
  • When one object gets close enough to another, they snap together and freeze in place, creating the illusion that they're connected.
  • PunRCP callbacks where used in order to execute the call of freezing for all users with help of Photon View and Photon Rigidbody View.
  • While an object is within snapping range, its outline turns green to signal that it can be attached.
